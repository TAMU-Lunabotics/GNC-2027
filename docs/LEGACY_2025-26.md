# GNC Legacy Baseline — 2025–26

**Status: LEGACY — reference only**

The 2025–26 robot replaced the 2024–25 standard SLAM/Nav2 approach with team-developed perception, localization, navigation, and control. The choices below are historical design baselines, not automatic 2026–27 selections.

## 2025–26 Sensor / Perception Baseline
- **Unitree L1 4D LiDAR** selected at PDR.
- **BMI088 IMU** selected at PDR.
- **REV Through Bore Encoder** selected at PDR.
- Camera selection evolved from monocular to **RGB-D** after the selected monocular unit became unavailable.
- **Phidgets 3136** load/mass sensor was selected, with an FRC4122 fallback.
- Late-cycle architecture relied on multiple sensing sources rather than a single sensor.

## 2025–26 Algorithm Baseline
- **Guidance / planning:** A* with continuous updates; fuzzy augmentation considered if needed.
- **State estimation / navigation:** square-root filter selected, with possible SLAM integration if schedule allowed.
- **Control:** PID baseline; LQR considered for selected optimal-control use cases.
- The team explicitly moved away from the prior standard SLAM/Nav2 stack toward team-written perception/localization/navigation code.

## Historical 2024–25 Predecessor
- Compute: Raspberry Pi 4 Model B.
- Navigation: standard SLAM/Nav2-style stack.
- The 2025–26 redesign was intended to address limitations of this earlier approach.

## Reuse Rule
Sensor models, filters, planners, controllers, coordinate conventions, gains, and old ROS interfaces must be treated as **legacy candidates** until re-evaluated for the 2026–27 rules and current robot design.
