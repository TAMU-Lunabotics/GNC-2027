# Contributing

## Branches
Create a short-lived branch from `main`:
- `feature/<name>`
- `fix/<name>`
- `test/<name>`

## Pull Requests
- Keep each PR focused on one change.
- Build/test locally before requesting review.
- Explain any hardware or cross-subsystem dependency.
- Update `docs/INTERFACES.md` when a topic, message, frame, unit, rate, or command contract changes.
- Do not commit generated ROS 2 build folders, logs, rosbags, credentials, or machine-specific files.

`main` should remain integration-ready.
